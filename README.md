# Printless Window Cleaning homepage demo

A static, responsive homepage redesign for Printless Window Cleaning. Open `index.html` locally or publish the repository root with GitHub Pages. No build step or backend is required. The quote buttons link to the existing business contact page; phone and email links use the business's published contact details.

Original logo and photographs are referenced from the existing site's image CDN because direct asset downloads were unavailable in the development environment. They require an internet connection and remain subject to the source host's availability. Business details and testimonial were sourced from the existing homepage, services, and about pages. This demo uses a noindex directive.

The original site's CSS was not accessible for exact color extraction in this environment; the muted green and dark neutral palette is a provisional design choice, not a verified brand palette. Verify against the source styles before production.
